# 🌟 Awesome Opportunity Repositories

> A curated meta-directory of the maximum possible GitHub repositories tracking
> **internships, summer schools, scholarships, research fellowships, travel
> grants, and student programs**.

Inspired by
[hazratali/awesome-ai-summerschool](https://github.com/hazratali/awesome-ai-summerschool),
this catalog indexes the best community-driven and automated trackers on GitHub
across computer science, artificial intelligence, quantitative finance, academic
research, and engineering.

## Programmatic Access (JSON)

This repository includes a machine-readable JSON catalog at
[`opportunities_repositories.json`](opportunities_repositories.json). You can
parse it in Python, JavaScript, or any language:

```python
import json

with open("opportunities_repositories.json", "r") as f:
    data = json.load(f)

print(f"Total repositories indexed: {len(data['repositories'])}")
for repo in data["repositories"]:
    print(f"- {repo['name']} ({repo['category']}): {repo['url']}")
```
